📲 iOS 전용 앱 설치 완료하기
✅ "프로필이 다운로드됨" 창이 떴다면 성공입니다!
애플(iPhone/iPad) 보안 정책상 다운로드된 전용 앱은 [설정] 앱에서 [설치]를 눌러야 바탕화면에 아이콘이 생성됩니다.
1
화면에 뜬 "프로필이 다운로드됨" 알림창에서 [닫기]를 누른 뒤, 위 [⚙️ 설정 앱 열기] 버튼을 누릅니다.
2
설정 앱 상단(Apple ID 바로 아래)에 새로 생긴 [프로필이 다운로드됨]을 터치합니다.
3
우측 상단 [설치]를 누르면 바탕화면에 오뺀 전용 앱이 즉시 생성됩니다!
