# 🎸 오늘부터 밴드부 (오뺀) - 모바일 전용 동호회 운영 시스템

사내/동호회 밴드부 '오늘부터 밴드부(약칭: 오뺀)'의 원활한 합주실 예약과 공지사항 전달을 위한 모바일 전용 웹 플랫폼입니다.

---

## 🔒 1. 인프라 격리 보장 (Zero Regression & Zero Contamination)
- **기존 배송스케줄 시스템과 100% 완전 분리**:
  - 기존 Supabase/Firebase 프로젝트 및 API 연동 일체 배제
  - 독립 SQLite DB (`data/band_club.db`) 사용으로 쿼터 소진 및 간섭 0%
  - 포트 5500 사용으로 기존 8080 포트와 충돌 원천 방지

---

## 📱 2. 주요 기능
1. **합주실 타임슬롯 예약 (`📅 합주예약`)**:
   - 8개 기본 표준 슬롯(08:00~24:00) 및 맞춤 시간 직접 예약
   - 겹치는 시간대 예약 자동 차단 (409 Conflict 방어)
   - 본인 확인용 간편 4자리 비밀번호(PIN) 기반 예약/취소
2. **공지사항 게시판 (`📢 공지사항`)**:
   - 상단 필독(PIN) 공지 배지 고정
   - 분류 태그 (필독, 합주, 회비, 행사, 일반)
   - 4자리 PIN 기반 공지 작성 및 삭제
3. **합주곡 레퍼토리 (`🎵 합주곡`)**:
   - 곡명, 아티스트, Key(조), 템포(BPM), 연습상태
   - 유튜브 영상 링크 및 악보 링크 원클릭 연결
4. **부원 명부 (`👥 부원명부`)**:
   - 보컬, 일렉, 통기타, 베이스, 드럼, 건반 등 파트별/직책별 카드 뷰

---

## 🚀 3. 로컬 테스트 및 구동 방법
- `서버_실행.bat` 더블 클릭 또는:


## 🌐 4. 외부 LTE/5G 24시간 모바일 접속 배포 방법
부원들이 PC 가동 여부와 관계없이 LTE/5G로 상시 접속하려면 무료 클라우드 호스팅에 배포할 수 있습니다:

### 방법 A: Render.com 24시간 무료 웹 서비스 배포 (추천)
1. GitHub에 본 `오뺀` 디렉터리를 비공개 또는 공개 리포지토리로 푸시합니다.
2. [Render.com](https://render.com)에서 **New Web Service** 생성 후 본 리포지토리를 연결합니다.
3. Build Command: `pip install -r requirements.txt || true`
4. Start Command: `python server.py`
5. 발급되는 무료 고유 HTTPS 링크(예: `https://oppaen-band.onrender.com`)를 카톡 단톡방에 공유하면 끝!

### 방법 B: Vercel / Cloudflare Pages 배포
- 정적 프론트엔드(`public/`) 배포 지원.
